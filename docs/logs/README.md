# Progress Log Archives

Monthly archive files (`YYYY-MM.md`) holding entries that have rolled out of
`docs/PROGRESS_LOG.md`'s "Recent entries" window. Maintained by the
`log-progress` skill during rotation — don't hand-edit these unless
correcting a factual error in a past entry.

**Read a specific month only when you need historical context that the
"Current State" summary in `PROGRESS_LOG.md` doesn't already cover** — e.g.
"why did we choose X back in March?" Don't read these by default; that
defeats the entire purpose of keeping the main log small and fast to absorb.
